## 🚀 Como Executar
1. Clone o repositório:
```bash
git clone https://github.com/carlusnz-dev/portfolio-pessoal.git
cd portfolio
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor:
```bash
npm run dev
```

Acesse: [http://localhost:3000](http://localhost:3000)
